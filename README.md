# Волна — музыкальный плеер на Java (Android)

Офлайн-плеер без подписок и рекламы. Внутри 10 твоих треков.

## Что умеет
- Список треков, поиск по названию/исполнителю, «Любимые» (сердечко)
- Перемешать, повтор (выкл / все / один), перемотка, следующий/предыдущий
- Игра в фоне + уведомление с кнопками + управление с экрана блокировки и наушников
- «+ Свои треки» — добавить любые mp3 с телефона (долгое нажатие на такой трек — убрать)

## Как получить APK
1. Залей папку на GitHub (репозиторий).
2. Вкладка Actions → "Build APK" → дождись зелёной галочки.
3. В Artifacts скачай `Volna-debug-apk` → внутри `app-debug.apk`.

Или в Android Studio: File → Open → эта папка → Run.

## Как добавить песни в сам APK
1. Положи mp3 в `app/src/main/assets/audio/` (имена латиницей, напр. `11.mp3`).
2. Добавь запись в `app/src/main/assets/tracks.json`:
   `{"id":"11","title":"Название","artist":"Исполнитель","duration":200,"src":"audio/11.mp3"}`
   (duration — в секундах, можно примерно).
